## 📂Файловый менеджер для CMD
### ⌨️Требования для запука
```
◽Windows 10 / Windows 11
◽Консоль (cmd.exe, Windows Terminal или PowerShell)
◽g++ 8.x и новее
```
### 🧾Возможности:
🔹Перемещение по директориям 
```
↑↓ Стрелки отвечают за перемещение по списку объектов текущей директории
⤶ Enter - Вход в дочернюю директорию
⌫ Backspace - Выход в родительскую директорию
```
🔹Работа с файлами
```
𝐃 - Удалить файл
𝐌 - Поставить метку на файл
𝐂 - Копировать отмеченный файл в текущую директорию
𝐗 - Вырезать отмеченный файл в текущую директорию
𝐅 - Открыть текстовый файл для чтения
```
🔹Завершение работы программы
```
𝐄𝐬𝐜 - Выход из программы
```

### 🎛️Интерфейс пользователя
```
💠Сверху отображается текущая директория и количество элементов в ней
💠Ниже находится основная рабочая область в виде списка из папок и файлов
💠Под рабочей областью находится список основных команд с кнопками на которые они назначены
💠В самом низу будет отображаться отмеченный файл, если он существует
```
### 🎨Обозначения в рабочей области
```
[𝐃𝐈𝐑] - Обозначение директории
[𝐌𝐀𝐑𝐊] - Обозначение отмеченного файла
| - Разделительная линия, после которой идет размер файла в байтах
```
## 📚Особенности программы
```
🔵Не поддерживает имена файлов и папок на русском языке
🔵При длинном названии файла могут возникнуть проблемы с отображением интерфейса
🔵При открытии текстового файла могут возникать проблемы с его прокруткой
```
